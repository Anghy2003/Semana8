# UEES UCOM0310 — Semana 8 — Proyecto base

Proyecto base para las actividades de integración final.

## Requisitos
- Java 21
- Maven
- Git

## Ejecutar pruebas
```bash
mvn clean test
```

## Ejecutar aplicación
```bash
mvn spring-boot:run
```

## Endpoint inicial
`GET http://localhost:8080/api/reservas/salud`

## Cobertura
Después de `mvn clean test`, abrir:
`target/site/jacoco/index.html`
